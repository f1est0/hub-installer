# Загрузчик агента мониторинга HubSentry

Краткое описание самого HubSentry собрано в отдельном файле: [HUBSENTRY.md](HUBSENTRY.md).

Здесь лежит один файл, `hub-install.sh`, и его контрольная сумма. Репозиторий нужен только для независимой проверки:
файл можно сверить с копией, которую вам дал владелец хаба, и убедиться, что по дороге его не подменили.

Загрузчик короткий (около 70 строк), перед запуском его можно прочитать целиком: `less hub-install.sh`.
Он ничего не устанавливает сам: скачивает с хаба манифест и подпись, проверяет подпись вшитым открытым ключом владельца,
сверяет контрольные суммы установщика и агента и только потом запускает установщик. В файле нет секретов.

## Проверка

```bash
sha256sum hub-install.sh
```

Результат должен совпасть с `SHA256SUMS` в этом репозитории и с суммой, которую вам передал владелец хаба.
Если не совпал, файл запускать нельзя.

Отпечаток вшитого открытого ключа (должен совпасть с `release-pub.pem` из этого репозитория):

```bash
sed -n '/BEGIN PUBLIC KEY/,/END PUBLIC KEY/p' hub-install.sh | openssl pkey -pubin -outform DER | openssl dgst -sha256
```

Ожидаемое значение: `d3bfddffeab44f4632cd86e7eac9e302da28a277373f52ddcf628c69f485e64e`.

## Запуск

```bash
sudo sh hub-install.sh
```

Токен проекта вводится при установке и хранится только на вашем сервере.
